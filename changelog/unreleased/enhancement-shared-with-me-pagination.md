Enhancement: Paginate the Shared with me view

Shared with me rendered every share it received in one list, so an account
with a large number of shares produced a very long page and a slow first
render. The sections are now paginated like other file listings.

The help text describing how public link access is granted has also been
reworded: it previously stated that no login is required and then explained
when a login is required, which read as a contradiction.
